## DNS:
protocolo dns se encarga de traducir nombre a ip y viceversa, estos servidores estan distribuidos y tienen distintas direcciones para ir resolviendo despacio.
#### funcionamiento:
se genera una petición de pc a server, el server que responde es el dns y resuelve a que ip me tengo que conectar. Luego desde allí me conecto a la web o donde debo hacerlo
#### jerarquia de dominios: 
para establecer un control y una organización de dominios, parte generica (dom/edu/org/net) y por paises(ar/us/uk).
#### Organización de URL(uniform resource locator)
1- protocolo
2-  subdominio
3-  dominio
4- que nivel de dominio 

la primer búsqueda es interna(local) y es una especia de caché, luego hace un salto directamente al servidor.
## HTTP: 
protocolo de transferencia de HiperTexto
- Get recupera datos el server
- Post envía datos al server
- Put: actualiza o crea 
- Delete borra un recurso el servidor
hace un get index llama al servidor y devuelve el msj 200 ok si esta todo bien y devuelve el html.index para el browser
#### mensajes: 
- 100
- 200 de exito
- 300 
- 400 errores de cliente
- 500 problemas del servidor
