#### Seguridad:

#### Proxy:
Funciona como una memoria a caché a nivel de red y permite tener un único punto de salida para dar mas seguridad ( por ejemplo que desde tu internet no puedan conectarse a x pagina web ). divide la búsqueda a varios servidores y devuelve la respuestas al cliente, ofrece memoria caché y control de acceso web.
