#### Utilizando Swing con el plugin WindowBuilder
El frame o Jframe es nuestra pantalla o lo que vemos el desginer
Se puede reaccionar antes los eventos que realiza el usuario por ejemplo tocar un boton
Podemos elegir la ventana del SO que nosotros queramos entre las opciones, sino siempre usaria el del sistema.
### Solapa Desgin:
Permite acceder a la definicion grafica de la ventana principal
### Absolute layout:
Nos permite acomodar los diferentes componentes visuales en la ventana en las posiciones que nosotros queramos en coordenas (X:Y), existen distinton tipos de layout

## Componentes

Los componentes tienen varios propiedades para poder jugar con ellos, esto se puede hacer desde codigo o desde la interfaz grafica, los componentes son los basicos que podria tener una pagina web
### Jlabel:
Permite poner un texto sobre la ventana grafica

### JtextField:
Permite que el usuario coloque texto

En propiedades podemos cambiar los nombres de los componentes visuales que agregamos a nuestra ventana, por ejemplo un button puede tener nombre boton1 y sobre el boton la palabra "enviar".

### Boton:
Se puede acceder a la clase boton para poder acceder al codigo asociado al boton,por ejemplo podemos sumar los valores de los textfield
