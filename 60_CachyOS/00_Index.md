## 🚀 Accesos rápidos

### Comandos que más uso

```bash
sudo apt update && sudo apt upgrade   # actualizar sistema
df -h                                  # ver espacio en disco
htop                                   # monitor del sistema
```

### Atajos que más uso

|Atajo|Acción|
|---|---|
|`Ctrl + Alt + T`|Abrir terminal|
|`Super`|Abrir menú|
|`Alt + F2`|Ejecutar comando rápido|
