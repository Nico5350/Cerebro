## 🎨 Software de diseño 3D

### Para principiantes

#### Tinkercad (gratis, navegador)

- **URL:** https://tinkercad.com
- **Ideal para:** piezas funcionales, geometrías simples
- **Curva de aprendizaje:** 1–2 horas para lo básico
- **Lo mejor:** exporta directo a STL, no requiere instalación
- **Limitación:** no sirve para objetos orgánicos complejos

#### Bambu Studio (gratis)

- **URL:** https://bambulab.com/download/studio
- **Uso:** slicer oficial para la A1
- **Siempre actualizarlo** a la última versión
- Incluye perfiles optimizados para todos los materiales Bambu

### Para nivel intermedio

#### Fusion 360 (gratis para uso personal)

- **URL:** https://www.autodesk.com/products/fusion-360
- **Ideal para:** piezas técnicas, ingeniería, ajustes precisos
- **Curva de aprendizaje:** 2–4 semanas para uso básico productivo
- **Muy potente** para piezas de repuesto y herramientas

#### FreeCAD (gratis, open source)

- **URL:** https://freecad.org
- **Alternativa** a Fusion 360, sin restricciones de licencia
- Más complejo pero completamente libre

### Para diseño artístico / orgánico

#### Blender (gratis, open source)

- **URL:** https://blender.org
- **Ideal para:** figuras, personajes, arte, objetos decorativos
- **Curva de aprendizaje:** alta, pero comunidad y tutoriales enormes
- **Perfecta combinación:** Blender (modelado) + Bambu Studio (slicing)

#### ZBrush (pago)

- Para miniaturas y esculturas digitales de alta calidad
- Usado por diseñadores profesionales de gaming/coleccionables

### Flujo de trabajo recomendado

```
Diseño → Exportar como STL/3MF → Importar en Bambu Studio
         (Tinkercad/Fusion/Blender)         → Configurar parámetros
                                             → Enviar a impresora
```
