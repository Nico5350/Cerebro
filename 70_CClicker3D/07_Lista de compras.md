## 📦 Lista de compras iniciales

### Consumibles básicos

- [ ] 2–3 rollos de PLA+ (colores versátiles: negro, blanco, uno llamativo)
- [ ] 1 rollo de PETG (para piezas funcionales)
- [ ] 1 rollo de PLA Silk (para mostrar capacidad decorativa)
- [ ] Alcohol isopropílico 70%+ (limpieza cama)
- [ ] Laca para el cabello (alternativa para adherencia PETG/ABS)

### Herramientas

- [ ] Calibre digital (~$5–10 en ML)
- [ ] Espátula metálica (si no viene incluida)
- [ ] Pinzas largas (para limpiar interior nozzle)
- [ ] Cepillo de latón (limpieza nozzle exterior)
- [ ] Guantes de nitrilo (para manipular piezas calientes)

### Para el negocio

- [ ] Fondo fotográfico (papel blanco A3 o vinilo)
- [ ] Linterna o lámpara LED para fotos
- [ ] Celular con buena cámara (o luz suficiente)
- [ ] Bolsas o cajas para envíos
