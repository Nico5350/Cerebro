## 💰 Fórmula de costos

### Cálculo completo

```
COSTO MATERIAL     = (precio_filamento / 1000) × gramos × (1 + %desperdicio)
COSTO ELECTRICIDAD = horas_impresión × 0.30 kW × precio_kWh
COSTO MANO DE OBRA = horas_trabajo_manual × tarifa_hora
AMORTIZACIÓN       = costo_impresora / piezas_estimadas
─────────────────────────────────────────────────────
COSTO TOTAL        = suma de todos los anteriores
PRECIO DE VENTA    = COSTO TOTAL × (1 + margen)
```

### Ejemplo real — soporte de pared multicolor

```
Material: PLA, 80g, desperdicio 10%
Precio filamento: $22/kg
→ Costo material: (22/1000) × 80 × 1.10 = $1.94

Electricidad: 3h × 0.30 kW × $0.07/kWh = $0.063

Mano de obra: 0.5h × $3/h = $1.50

Amortización: $760 / 500 piezas = $1.52

COSTO TOTAL: $1.94 + $0.06 + $1.50 + $1.52 = $5.02

Con 60% de margen → PRECIO DE VENTA: $8.03 USD
En ARS (TC $1200): ~$9.600
```

### Márgenes de referencia

|Margen|Evaluación|
|---|---|
|< 30%|Peligroso — cualquier imprevisto genera pérdida|
|30–50%|Aceptable para productos muy competitivos|
|50–80%|Saludable — recomendado para la mayoría|
|80–150%|Ideal para diseños propios / alta demanda|
|+150%|Posible con productos únicos o customizados|

> 💡 **Usá la calculadora HTML** incluida en este vault para calcular cada producto.

## 📈 Estrategia de negocio

### Fase 1 — Primeros 3 meses (aprender + testear)

- [ ] Dominar la calibración de la máquina
- [ ] Probar 3–4 tipos de filamento
- [ ] Imprimir 10–15 productos de plataformas gratuitas
- [ ] Fotografiar BIEN cada pieza (luz natural, fondo neutro)
- [ ] Publicar en MercadoLibre con descripción detallada
- [ ] Objetivo: recuperar el 20–30% del costo de la impresora

### Fase 2 — Meses 3–6 (validar nicho)

- [ ] Identificar qué productos se vendieron mejor
- [ ] Aprender Tinkercad o Fusion 360 para customizaciones
- [ ] Ofrecer personalización (nombre, color, medidas)
- [ ] Crear presencia en Instagram mostrando el proceso
- [ ] Construir base de clientes recurrentes

### Fase 3 — Meses 6–12 (escalar)

- [ ] Crear catálogo propio en Tiendanube
- [ ] Diseñar productos exclusivos que no se consigan fácil
- [ ] Subir diseños propios a MakerWorld / Printables para visibilidad
- [ ] Evaluar segunda impresora si la demanda lo justifica
- [ ] Considerar vender en Etsy al exterior

### Diferenciadores clave con la A1 Combo

1. **Multicolor** → la mayoría de impresores de la competencia no tiene AMS → precio premium justificado
2. **Velocidad** → podés producir más unidades por día que con impresoras lentas
3. **Personalización** → combiná diseño propio + multicolor = producto único

## 🛒 Dónde vender en Argentina

### Plataformas

#### MercadoLibre

- **Comisión:** ~12–18% + IVA sobre comisión
- **Ideal para:** volumen, productos conocidos, primeros pasos
- **Tips:**
    - Título con palabras clave descriptivas
    - Fotos con fondo blanco o neutro
    - Ofrecer variantes de color como opciones
    - Responder preguntas rápido (afecta el ranking)

#### Instagram / TikTok

- **Costo:** $0
- **Ideal para:** nichos visuales, construir marca, clientes directos
- **Tips:**
    - Mostrar el proceso de impresión (timelapse) = alto engagement
    - Antes/después si es pieza de repuesto o mejora
    - Stories mostrando pedidos personalizados
    - Usar hashtags: #impresion3d #impresion3dargentina #bambulab

#### Tiendanube

- **Costo:** desde $0 (plan gratuito con comisión)
- **Ideal para:** escalar, tener imagen profesional, evitar dependencia de ML
- **Tips:**
    - Integrar con MercadoPago
    - Crear categorías claras (hogar, gaming, mascotas, etc.)
    - Mostrar fotos de las piezas en uso real

#### Etsy (exportación)

- **Comisión:** 6.5% + tarifa fija por listado
- **Ideal para:** diseños únicos, miniaturas, arte, nichos específicos
- **Tips:**
    - Cobrar en USD → excelente para el negocio
    - Describir el proceso de impresión como artesanal
    - Ofrecer personalización (nombre propio, colores)
    - Calcular bien el costo de envío internacional

### Logística en Argentina

- **Andreani / OCA** → más confiable para piezas frágiles
- **MercadoEnvíos** → integrado con ML, más simple al principio
- **Empaquetar bien** → burbuja + caja rígida para piezas delicadas
- **Precio de envío** → incluirlo en el precio o cotizarlo aparte según tamaño
