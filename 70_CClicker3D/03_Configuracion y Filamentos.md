## 🖥️ Configuración de Bambu Studio

### Ajustes recomendados para negocio

|Parámetro|PLA|PETG|TPU|
|---|---|---|---|
|Layer height|0.2mm|0.2mm|0.2mm|
|Infill % (funcional)|15–20%|20–25%|15%|
|Infill % (decorativo)|10–15%|—|—|
|Perímetros|3|3–4|3|
|Soporte|Auto|Auto|Evitar|
|Velocidad|250 mm/s|180 mm/s|80 mm/s|

### Perfiles útiles para la A1

- Usar siempre los perfiles **Bambu Lab** incluidos → mejor resultado
- Para marcas de filamento no-Bambu → bajar velocidad 20%
- Activar **Adaptive Layer Height** para piezas orgánicas o con curvas
