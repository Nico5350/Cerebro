# Bitacoras
### [[Inidice de Bitacoras]]

```dataview
TABLE 
    ip_local AS "Dirección IP", 
    puertos AS "Puertos Abiertos", 
    estado AS "Estado",
    tags AS "Categorías"
FROM "20_Server"
WHERE tipo = "ficha_contenedor"
SORT estado DESC
```
