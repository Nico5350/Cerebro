# ⌨️ Atajos de Teclado

#mint #atajo

> Shortcuts para Linux Mint con escritorio Cinnamon.  
> `Super` = tecla Windows

---

## 🖥️ Escritorio y ventanas (Cinnamon)

|Atajo|Acción|
|---|---|
|`Super`|Abrir menú de aplicaciones|
|`Ctrl + Alt + T`|Abrir terminal|
|`Alt + F2`|Ejecutar comando rápido|
|`Alt + F4`|Cerrar ventana activa|
|`Alt + Tab`|Cambiar entre ventanas abiertas|
|`Alt + F6`|Cambiar entre ventanas de la misma app|
|`Super + D`|Mostrar escritorio (minimizar todo)|
|`Super + L`|Bloquear pantalla|
|`Super + E`|Abrir gestor de archivos (Nemo)|
|`Super + ↑`|Maximizar ventana|
|`Super + ↓`|Restaurar / minimizar ventana|
|`Super + ←`|Pegar ventana a la izquierda|
|`Super + →`|Pegar ventana a la derecha|
|`Super + Tab`|Exposé de ventanas|
|`Ctrl + Alt + ←/→`|Cambiar de espacio de trabajo|
|`Ctrl + Alt + Shift + ←/→`|Mover ventana al espacio de trabajo|

---

## 📸 Capturas de pantalla

|Atajo|Acción|
|---|---|
|`Print Screen`|Captura pantalla completa|
|`Alt + Print Screen`|Captura ventana activa|
|`Shift + Print Screen`|Captura área seleccionada|

## 🖥️ Terminal

|Atajo|Acción|
|---|---|
|`Ctrl + C`|Cancelar comando en ejecución|
|`Ctrl + Z`|Suspender proceso (pasa a segundo plano)|
|`Ctrl + D`|Cerrar terminal / sesión|
|`Ctrl + L`|Limpiar pantalla|
|`Ctrl + R`|Buscar en historial de comandos|
|`Ctrl + A`|Ir al inicio de la línea|
|`Ctrl + E`|Ir al final de la línea|
|`Ctrl + U`|Borrar desde cursor hasta inicio|
|`Ctrl + K`|Borrar desde cursor hasta final|
|`Ctrl + W`|Borrar palabra anterior|
|`Tab`|Autocompletar comando o ruta|
|`Tab Tab`|Mostrar todas las opciones posibles|
|`↑ / ↓`|Navegar historial de comandos|
|`Ctrl + Shift + C`|Copiar texto seleccionado|
|`Ctrl + Shift + V`|Pegar en terminal|
|`Ctrl + Shift + T`|Nueva pestaña en terminal|
|`Ctrl + Shift + W`|Cerrar pestaña|
|`Ctrl + PgUp / PgDn`|Cambiar entre pestañas|

## ⚙️ Personalizar atajos en Cinnamon

Para ver y modificar todos los atajos:

- Menú → Preferencias → Configuración del Sistema → **Teclado** → pestaña **Atajos de teclado**
- O desde terminal: `cinnamon-settings keyboard`
